# Get To Know Me 👋

My personal portfolio website built with Next.js and React.

🌐 **Live site:** [anosharehan.netlify.app](https://anosharehan.netlify.app)

## About

A fullscreen scroll-snap portfolio showcasing my experience, skills, and education as a software engineer with 4+ years of backend and full-stack experience.

## Built With

- [Next.js](https://nextjs.org/) — React framework
- [React](https://react.dev/) — UI library
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- Deployed on [Netlify](https://netlify.com)

## Sections

- About
- Work Experience
- Skills & Technologies
- Education

## Running Locally
```bash
git clone https://github.com/yourusername/get-to-know-me.git
cd get-to-know-me
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
